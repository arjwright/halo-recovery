Halo Recovery

Connect, recover a stuck device, or write a simple HUD.

Connection

Connect first. Recovery sends the standard break and reset signals.

Write a HUD

Each action overwrites main.lua on the glasses and asks before writing.

Diagnostics

Tests may interrupt the current HUD. Run a dashboard action or reset afterward to restore it.

Individual recovery commands

Wipe removes Lua files from the glasses while preserving device settings. Confirm prompts are shown before destructive actions.

Works in Chrome, Edge, and Opera on desktop and Android. Web Bluetooth is not supported by iOS Safari. This page writes directly to the connected glasses; it does not send device data to a server.
